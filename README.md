# ☀️ Aryian's Energy Solution | Engineering Clean Energy

> **A high-end industrial engineering web platform for solar energy systems, commercial battery hubs, and solar ROI investment modeling.**

---

## 📌 Project Overview
**Aryian's Energy Solution** is an industrial clean energy web application designed for a commercial solar technology provider. Showcasing tier-1 monocrystalline solar panels, high-voltage battery storage hubs, and commercial microgrids, the platform includes a dynamic solar investment savings simulator, engineering facility walkthroughs, and detailed hardware specification documentation.

---

## ✨ Key Features
- **💡 Solar Investment & ROI Simulator:** Interactive financial calculator (`Portfolio.tsx`, Recharts) calculating kilowatt capacity, monthly utility bill offsets, payback periods, and 25-year lifetime savings.
- **🔋 Battery Storage Hub & Hardware Specs:** Comprehensive technical breakdowns of commercial energy storage systems (`BatteriesHub.tsx`, `Batteries.tsx`, `ProductPager.tsx`).
- **🏭 Virtual Engineering Facility Tour:** Visual journey through production facilities, cell testing laboratories, and robotic assembly lines (`FacilityTour.tsx`).
- **📑 Technical Consultation & Energy Audits:** Interactive consultation inquiry pipeline for scheduling on-site commercial engineering assessments.
- **✨ Fluid Modern Design:** Built with dark architectural typography, smooth Framer Motion scroll interactions, and responsive charts.

---

## 🛠️ Tech Stack
- **Frontend:** React 18, Vite, TypeScript
- **Styling:** Tailwind CSS, PostCSS
- **Data Visualization & Charts:** Recharts
- **Animations & Icons:** Framer Motion (`framer-motion`), Lucide React
- **Routing:** React Router DOM (HashRouter)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/)

### Installation
```bash
git clone git@github.com:xxsoloxxleveling-sketch/Solar.git
cd Solar
npm install
```

### Running Locally
```bash
npm run dev
```
